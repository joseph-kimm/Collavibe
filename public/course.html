The five weeks

Prepare. Build. Test. Explain.

Each lesson includes preparation to watch/read at home, a complete 120-minute class plan, an exit check, and the next assignment. Open a week to see the details.

Assignments

Three small individual builds, a team charter, and a final group app. Use the evidence checks to review your work. Feedback is descriptive; there are no grades or contribution rankings.

Two APIs, one useful question.

Use the directory to discover ideas, then verify the provider documentation. The guided starter has live requests, synthetic offline data, and controls for partial failure. It is a starting point to revise, not a finished assignment to submit unchanged.

Storage and access rules

Use the local storage explanation to inspect the idea, then the SQL lab for real database-policy evidence. The SQL script uses fictional records and rolls back its work.
