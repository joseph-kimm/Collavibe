Collavibe holds the shared plan and session handoffs. Your agent still writes the code in your own repository.

What does Collavibe actually see?

It receives the project details, structured handoffs, and Git snapshots that your agent sends. It does not automatically read your whole chat, import your source code, or watch GitHub pushes. Saving a handoff does not commit or push code.

An MCP-compatible client is required for the agent connection. Setup options depend on your client.
