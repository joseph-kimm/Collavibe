01

ChatGPT visual setup

No terminal needed. Add Collavibe from ChatGPT’s Plugins screen.

  1. Open ChatGPT Plugins, click +, then choose Add custom MCP server.
  2. Name it Collavibe, paste the MCP URL above, and select No authentication.
  3. Create and install the plugin. In a Work chat, invoke @Collavibe and paste the starter prompt below.
Open ChatGPT Plugins ↗
02

Claude visual setup

Add the hosted server as a custom connector in Claude or Claude Desktop.

  1. Open Settings → Connectors and choose Add custom connector.
  2. Name it Collavibe, paste the MCP URL above, and add it.
  3. Enable Collavibe from Search and tools in a new chat, then paste the starter prompt below.
Open Claude Connectors ↗
Claude Code alternativeclaude mcp add --transport http --scope user collavibe https://collavibe.vercel.app/mcp
03

Codex setup

Register the hosted endpoint once, then use it from any repository.

Run in Terminalcodex mcp add collavibe --url https://collavibe.vercel.app/mcp

Run codex mcp list to verify the connection. Then open your repository in Codex and paste the starter prompt below.

04

Cursor or another MCP client

Use the hosted URL with any client that supports remote Streamable HTTP MCP servers.

Cursor · ~/.cursor/mcp.json{"mcpServers":{"collavibe":{"url":"https://collavibe.vercel.app/mcp"}}}

For another client, create a remote HTTP MCP connection named Collavibe using the URL above. No local Collavibe server is required.
